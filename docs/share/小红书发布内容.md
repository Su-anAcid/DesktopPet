## 📝 正文（约 700 字，上限 1000 字，可直接粘贴）

上班摸鱼，不如上班摸猫 🐱

几个晚上用 WorkBuddy 搓了一只住在桌面上的像素小猫——
不占 Dock、不抢焦点，就安安静静趴在屏幕角落🐾
现在写代码都有猫陪着，工位瞬间被治愈了。

划重点：全程没手写一行代码，40 多轮对话，全靠「说」出来的。

它每天的生活：
🚶 自己在桌面散步，走到屏幕边上还会掉头
😴 走累了就地趴下打盹，头顶冒 Zzz
🙆 睡醒先伸个大大的懒腰，再慢悠悠站起来
🐾 坐下前先舔两遍爪子，坐稳了尾巴还会扫地
👀 起身之前先左右张望，像在过马路
❤️ 鼠标摸它一下，眼睛秒变爱心+冒爱心粒子
😾 平时不傻笑，神态是很真实的猫（甚至有点嫌弃）

🧠 vibecoding 一只猫的全过程：

第 1 句「做个桌面宠物」
→ 出来一只真的很丑的猫，冒的爱心还被窗口裁掉一半 😅

第 3 句「以这张照片为原型」
→ 发了张我家灰虎斑奶猫的照片，重绘之后终于像了

第 8 句「行走太丑，还比趴卧小太多」
→ 重画 4 帧步态，结果尾巴又穿模，再退回去改

第 15 句「加行走↔坐下的过渡」
→ 它开始有生活节奏了：舔爪、扫尾、起身前左右张望

第 25 句「舔毛时头要跟着嘴巴转」
→ 前两版只是把头平移，被我一眼识破退回重做，
   改成图层旋转才真的像在舔

第 40 句「做个 Windows 版」
→ 直接交叉编译出一个单文件 exe，发给我朋友就能跑

整个过程真的像养猫：先有一只丑猫，
然后一句话一句话，把它调教成你想象中的样子。
而且验收特别直观——改完让它当场走一圈，
丑不丑一眼就知道，这种即时反馈太上头了。

细节控狂喜：
▪️ 纯手绘像素帧，Retina 屏缩小也不糊不出格子
▪️ 灰虎斑 / 橘猫 / 黑猫 三种毛色，三种体型
▪️ 可固定位置：只锁拖动，动作照常
▪️ 开机自启 + 记住你上次的全部设置

最爽的是：不用铲屎、不掉毛、不会挠沙发，
开会的时候它比我还安静 🤫

macOS 和 Windows 都有，免费开源！
GitHub 搜「DesktopPet」就能下载，链接放评论区啦 ⬇️

## 🗂️ 真实过程素材库（没写进正文的细节，评论区/续集随便取用）

- 爱心显示不全：窗口高度是按趴卧算的，冒爱心时上方被裁掉一截 → 加高窗口才修好
- 猫缩小后出现「分格」：不是图片坏了，是渲染没有对齐整数物理像素，Retina 屏上很典型
- 尾巴穿模：行走帧里尾巴从身体中间长出来，把尾根挪到臀部上后方才自然
- 「舔毛时头部没有转动啊」：模型觉得平移头就够了，人眼看穿，必须真的旋转
- 表情改过两轮：一开始加了爱心眼，被提醒「平时要像真猫」，最后平时写实、摸猫才爱心
- 打包踩坑：macOS 首次打开要右键→打开（没有公证证书）；CI 在干净环境跑了三次才绿
- 全部像素帧是程序化画出来的（椭圆/三角形/逐格填色），不是手 point 的，所以改毛色只改调色板
